Conquest of Azerothcore by https://github.com/jealous-sound/azerothcore-wotlk-coa

------------------------------------------------------------------------

How to Start the Server:
1. Launch Conquest of Azerothcore.bat and select Option 1.
2. A new window will open, give it about 20 seconds then press any key when it says to.

How to Shut Down the Server:
1. Launch Conquest of Azerothcore.bat and select Option 2.

I made a GM account you can use already:
username: Admin
password: Password

How to Create an Account:
(Make sure the Server is running first)
1. Select Option 3.
2. Type you preferred Username, then Password, then Password again.
3. Choose if you want the account to be an admin or not.

How to Start the Client:
1. Launch Conquest of Azerothcore.bat and select Option 4.
